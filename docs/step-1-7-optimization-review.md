# Fixtech Demo v1.8 — รีวิวและปรับขั้น 1–7

**วันที่:** 2026-09-25  
**ขอบเขต:** ทบทวนเอกสารขั้น 1–7, code path ที่เกี่ยวข้อง และผลทดสอบบน PostgreSQL ชั่วคราว. การขยายไปใช้งานจริงยังเป็น [แผนรุ่นถัดไป](production-expansion-v1.md).

## หลักฐานที่ตรวจซ้ำ

- ติดตั้ง DDL 26 ตารางและ seed 8 บัญชีบน PostgreSQL 18.6 **ฐานชั่วคราวแยกจากฐานผู้ใช้**.
- `npm run check` ผ่าน; `npm test` บนฐานชั่วคราวผ่าน **30/30 ไม่มี skip**; schema unit tests ผ่าน **8/8**.
- Integration เพิ่มกรณี Draft ถูกแก้ระหว่างรอราคา/AI; ทั้งสองกรณีคืน `409 JOB_CHANGED` และไม่มี estimate/analysis run เก่าค้าง. ตรวจ no-op PATCH ไม่เปลี่ยน row version/analysis version, ปฏิเสธฟิลด์บริษัทของลูกค้าทั่วไป และคืน 400 สำหรับเขตผิด.
- Browser walkthrough ครบ 4 role จากการตรวจรับก่อนหน้ายังเป็นหลักฐาน UI หลักใน [validation](validation.md); รอบนี้เปลี่ยนเพียง preflight ไฟล์, ข้อความชำระเงิน และการ refresh เมื่อ conflict. ไม่ได้ทำ benchmark latency, load test หรือ WCAG audit เต็มรูปแบบ.

## ข้อจำกัดที่ต้องทราบ

- การปฏิเสธผล AI หลังถอน consent ป้องกันการ **บันทึกผลล้าสมัย**; ข้อมูลที่ส่งให้โมเดลก่อนถอนแล้วเรียกคืนไม่ได้. Demo จึงยังใช้ข้อมูลสังเคราะห์.
- `xmin` ใช้ได้กับ PostgreSQL ซึ่งเป็นฐานเป้าหมายปัจจุบัน; หากเปลี่ยนฐานข้อมูลต้องแทนด้วย version column/migration และทดสอบ concurrency ใหม่.
- ผลทดสอบยืนยันความถูกต้องของ flow ที่ครอบคลุม ไม่ได้พิสูจน์ว่าเวลา response เร็วขึ้นในตัวเลข; การลด write/การไม่สร้าง Draft จากไฟล์ผิดเป็นผลเชิงโครงสร้างที่ตรวจจากเส้นทางทำงาน.
